# Practice and Problems

The best way to learn is by solving problems.

## Practice Sites

| Site | Level | Notes |
|---|---|---|
| [Codeforces](https://codeforces.com/) | All | Excellent contests and editorials |
| [AtCoder](https://atcoder.jp/) | All | High-quality problems and weekly contests |
| [CodeChef](https://www.codechef.com/) | Beginner-Intermediate | Great for regular practice |
| [SPOJ](https://www.spoj.com/) | All | Classic judge with many problems |
| [UVa](https://uva.onlinejudge.org/) | All | Classic programming problems |
| [CSES](https://cses.fi/problemset/) | Beginner | Problems sorted by topic, highly recommended |

## Beginner Problems

1. [CSES - Weird Algorithm](https://cses.fi/problemset/task/1068) - Basic loops
2. [CSES - Repetitions](https://cses.fi/problemset/task/1069) - Arrays and logic
3. [CSES - Missing Number](https://cses.fi/problemset/task/1083) - Arithmetic
4. [Codeforces 4A - Watermelon](https://codeforces.com/problemset/problem/4/A) - Conditionals
5. [Codeforces 71A - Way Too Long Words](https://codeforces.com/problemset/problem/71/A) - String basics

## Intermediate Problems

1. [CSES - Two Sum](https://cses.fi/problemset/task/1640) - Searching
2. [CSES - Maximum Subarray Sum](https://cses.fi/problemset/task/1643) - Kadane's algorithm
3. [Codeforces 231A - Team](https://codeforces.com/problemset/task/231/A) - Simple logic

## Final Tips

- **Practice daily**: Even solving 1 problem per day helps
- **Read editorials**: If stuck, read the solution and understand the reasoning
- **Review your code**: Clean up and optimize after getting accepted
- **Participate in contests**: Great for improving under time pressure
- **Stay consistent**: Progress is gradual but solid
