# C++ Course for Competitive Programming

This course is designed to teach C++ from the ground up, with a focus on competitive programming, contests, and algorithmic problem solving.

## Objectives

- Learn the fundamentals of modern C++
- Master basic data structures and algorithms
- Develop fast coding skills and good practices
- Prepare for programming contests and coding challenges

## Prerequisites

- Basic programming knowledge (recommended)
- Willingness to practice by solving problems

## Course Index

1. [Introduction to C++](introduction.md)
2. [I/O and Data Types](io-and-data-types.md)
3. [Conditionals and Loops](conditionals-and-loops.md)
4. [Arrays and Vectors](arrays-and-vectors.md)
5. [Functions and Recursion](functions-and-recursion.md)
6. [STL Basics](stl-basics.md)

8. [Practice and Problems](practice-and-problems.md)

## How to Follow This Course

It is recommended to read the topics in order and practice with exercises after each lesson.
